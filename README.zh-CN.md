## 按照片选择风格

| 风格 | 适用照片 |
| --- | --- |
| 摄影与手绘故事 | 有明确物件、形状或动作，适合向下延伸出小故事的场景 |
| 水彩旅行手账 | 街景、建筑、自然风景、旅行场景、带环境的人像 |
| 七彩水墨双联 | 夜间灯光、水面、植物、建筑、动物、旅行场景 |
| 纸浆浅浮雕海报 | 建筑、花卉、树木、静物、风景、带环境的人像 |
| 柔和渐变双联 | 花叶、鸟类、动物、水面、树林、夜景、建筑、带环境的人像 |

生成人像时需要额外检查脸部。有些 Skill 附带脚本，可以把原片面部直接放回成品；仅靠提示词不能保证原脸不变。

## Photo to Soft Gradient · 照片转柔和渐变双联

每张照片制作一张 **9:16竖版图**。顶部保留真实原图的 **16:9裁切**，只裁切和等比例缩放，不调色、不修脸、不用生成图代替。

先生成下方艺术图。保留少量有辨识度的主体细节，重新安排尺度、位置和空间。用 **3—5片大小不同的柔和渐变色场** 交叠，底色为深蓝、墨紫、深绿或原片暗色。让至少一片色场穿过主体边缘，使部分轮廓化为半透明色光，同时保留清楚细节和宽阔安静区域。

不添加文字、边框、水印、霓虹描边、星空、浓烟、粗颗粒或纸张肌理。下方完成后，再把真实原片拼到顶部。

### 适用照片

| 照片类型 | 主要保留内容 |
| --- | --- |
| 花卉、叶片、枝条 | 花心、花瓣边缘、叶脉、连接关系和原片颜色 |
| 鸟类、鱼类、其他动物 | 物种、数量、姿态、身体轮廓 |
| 湖海、池塘、芦苇、倒影 | 岸线、植物形状、水波和真实倒影方向 |
| 树木、树林、自然风景 | 主干、枝条走向、叶形和主要地形 |
| 夜景、街景、建筑、门窗 | 光线方向、明确结构或有辨识度的物件 |
| 旅行人像、带环境的人像和合照 | 原脸、服饰、姿态和重要接触关系 |
| 面部特写、证件照、精确地图 | 不属于主要用途；此风格会改变空间并删减细节 |

默认成品 **1152×2048 PNG**。顶部 **1152×648**，下方 **1152×1400**；顶部约占总高度31.6%，不做等高两栏。

下方出现可辨识人脸时，保留原片五官、脸型、表情、眼镜和肤色。用检查过的蒙版回贴原脸，只等比例缩放和平移，面部核心不加渐变染色或透明效果。脚本会检查保存后的顶部是否与原片裁切缩放结果一致，也会检查保护区域是否与变换后的原片一致；它不会自动选裁切或识别人脸。

### 调用示例

```text
使用 $photo-to-soft-gradient，把这张照片做成9:16柔和渐变双联。
顶部保留真实原图的16:9裁切。
下方用3—5片交叠渐变色场重组主体，保留少量清楚细节和安静深色区域。
保留原脸，不添加文字或边框。
先生成下方，再把真实原图拼到顶部。
```

## 下载和安装

1. 在仓库首页点击 **Code → Download ZIP**。
2. 解压后打开 `skills/`。
3. 将需要的完整 Skill 文件夹复制到你的 AI 工具支持的技能目录，或按该工具提供的方法导入。
4. 上传自己的照片，让 AI 使用对应 Skill。

新风格的文件夹是 `skills/photo-to-soft-gradient/`。保留整个文件夹，不要只下载 `SKILL.md`。

## 使用条件

AI 工具需要能读取 Skill 和查看图片。真正生成艺术图还需要图像生成或编辑工具；**安装 Skill 不会自动安装图像模型或获得工具权限**。不同图像模型生成的结果可能不同。

新 Skill 的拼接脚本需要 Python 3 和 Pillow：

```bash
python -m pip install "Pillow>=10"
```

没有图像工具时，可以只编写提示词。没有普通图像拼接能力时，不能把生成模型重画的顶部说成未修改的原图。

## 添加其他 Skill

在 `skills/` 下新建独立文件夹，放入 `SKILL.md` 和必要文件，再更新两个 README 的表格。表格各行之间不要插入空行。

私人照片、账号资料和私人生成图片不要放进这个公开仓库。第三方示例图需要获得许可后再公开。
