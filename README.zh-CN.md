# Photo Skills · 照片技能合集

五种 AI 照片处理 Skill：把照片接成手绘、画成水彩手账、转成七彩水墨、做成纸张艺术海报，或重组为柔和渐变图。

## 照片接手绘 — photo-to-sketch-storytelling

上方保留照片的现场感。从原片中选择一个物件或形状，比如围巾、树枝、道路或倒影，让它向下延伸，逐渐变成暖白纸上的手绘。再加入一个小人物，和它产生明确的动作关系，比如行走、拉动、编织或划船。

用细铅笔线或墨线，加少量原片颜色。每张照片根据自身内容设计故事。默认是 **2:3竖版**。

**适用照片：**旅行场景、植物、衣物、静物、带环境的人像。有清楚形状或动作的照片尤其合适。

**调用示例：**

```text
使用 $photo-to-sketch-storytelling，把这张照片向下延伸成手绘。
选择原片中的一个物件，加入一个与它互动的小人物。
保留人物原脸。
```

## 水彩旅行手账 — photo-to-watercolor-journal

把整个场景画成细钢笔线条与柔和水彩，保留照片原来的宽高比例。绘画边缘逐渐淡入纸面；纸底颜色随场景调整，日景可以温暖一些，夜景可以偏冷、偏深。

右下角放 **四个纯色颜色样本**，颜色取自原片。底部加英文手写标题和一句简短英文。

**适用照片：**街景、建筑、山水、湖海、乡村、车站、夜景和带人物的旅行照。

**调用示例：**

```text
使用 $photo-to-watercolor-journal，把这张照片画成水彩旅行手账。
保留原比例，添加四个原片颜色样本，
并添加英文手写标题和一句简短英文。
```

## 七彩水墨 — photo-to-rainbow-ink-diptych

制作一张 **9:16竖版上下组合图**。上方是真实原图的 **16:9裁切**；下方把同一场景画成彩色水墨和水彩，带粗纸纹理。少量纸边或折叠跟随原片的形状和光线。

以原片主色为主，其他彩虹颜色少量加入。不添加文字、边框、星空或烟雾效果。

先生成下方艺术图，再把真实原片拼到顶部。顶部只裁切和等比例缩放，不调色、不重画。

**适用照片：**夜间灯光、街景、植物、花卉、水面、倒影、风景、建筑、动物和带环境的人像。

**调用示例：**

```text
使用 $photo-to-rainbow-ink-diptych，制作9:16上下组合图。
上方保留真实原图的16:9裁切，下方生成彩色水墨。
先生成下方，再拼接真实原图，不添加文字或边框。
```

## 纸张艺术海报 — photo-to-paper-relief-poster

每张照片做成一张独立的 **3:4竖版海报**。主体放在中下部偏右，约 **60%画面为暖白留白**。主体内部保留清楚细节，边缘逐渐变成薄纸纤维、撕纸和少量颜料，用柔和阴影表现轻微起伏。

左上放小号中文标题，下面配更小的英文短句、编号和一条取自原片颜色的短线。文字清楚、疏朗，不抢主体。默认成品为 **1536×2048 PNG**。

**适用照片：**建筑、园林、花卉、树木、静物、山水、湖海、森林、动物和带环境的人像。

**调用示例：**

```text
使用 $photo-to-paper-relief-poster，制作独立3:4纸张艺术海报。
保留大面积暖白留白，让主体边缘化为薄纸和纤维，
添加小号中文标题和英文短句，保留人物原脸。
```

## 柔和渐变 — photo-to-soft-gradient

制作一张 **9:16竖版上下组合图**。上方保留真实原图的 **16:9裁切**。下方选择少量能认出的细节，调整大小和位置，让形状像在悬浮，或延伸成柔和色光。

用 **3—5片大小不同的柔和颜色** 交叠、融合，底色为深蓝、墨紫、深绿或原片暗色，保留宽阔安静区域。让部分主体边缘淡入颜色，同时保留少量清楚细节。不添加文字、边框、霓虹描边、星空、浓烟或粗纸纹理。

先生成下方，再把真实原片拼到顶部。默认成品 **1152×2048 PNG**，顶部 **1152×648**，下方 **1152×1400**。

**适用照片：**花卉、叶片、鸟类、鱼类、其他动物、水面、倒影、树林、夜景、建筑和带环境的人像。

**调用示例：**

```text
使用 $photo-to-soft-gradient，制作9:16柔和渐变上下组合图。
上方保留真实原图，下方用3—5片柔和颜色交叠，
保留少量能认出的细节和人物原脸，不添加文字或边框。
```

## 保留人物原脸

要求 AI 保留原片五官、脸型、表情、眼镜和肤色。正脸和侧脸都需要检查。

部分 Skill 附带脚本，可以把原片面部直接放回成品。只有提示词不能保证原脸不变；所用 AI 如果只能生成图片、不能把原片像素放回去，需要特别核对脸部。

## 使用条件

AI 工具需要能读取 Skill、查看照片，并提供图像生成或编辑功能。**Skill 提供操作说明，不会自动安装图像模型。**不同模型的效果可能不同。

两种“上方原图、下方艺术图”的风格还需要普通图像拼接功能。相关脚本需要 Python 3 和 Pillow；纸张海报的文字脚本还需要 fontTools 和中文字体。具体要求见各 Skill 文件。

没有图像工具时，可以只编写提示词。面部特写、证件照和精确地图不属于这些艺术风格的主要用途。
