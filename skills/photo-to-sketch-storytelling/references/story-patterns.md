# 情节选择库

借鉴下列结构关系；只有原片确实含有对应元素时才采用。先选择来源，再改变形态，最后赋予人物动作。

| 原片元素 | 可延伸形态 | 清楚的动作关系 |
| --- | --- | --- |
| 编织枝条、藤编圆环 | 织物小路、拱桥、弯曲船沿 | 人物握住游离枝条编织；或撑杆推动枝条构成的小舟 |
| 枝叶、叶脉 | 薄叶吊床、叶脉帆面 | 人物坐在枝上，双手缝合边缘；线穿过叶脉结构 |
| 河面、湖面、倒影 | 可掀起的柔软长带 | 人物抓住末端，撑地后仰；原片倒影随带面弯曲 |
| 围巾、衣物现有下摆 | 织物小路、翻卷纸桥 | 人物踩住折叠处攀登，手握边缘纤维作扶手 |
| 马尾、毛发 | 丝线小路、流动编织结构 | 人物沿丝线行走、用杖支撑，轻持游离线作引导 |
| 鞍垫、毯子 | 连续的布料路径 | 人物弯腰握住末端，双脚撑地，将布料铺开 |
| 羽毛、鸟翼 | 层叠羽片阶梯 | 人物踩在羽片阶梯上，沿轮廓向上走 |
| 颜料、洗笔容器 | 流淌色带、细水道 | 人物开闸或导流；颜色明确来自原片颜料 |
| 布带、旗帜 | 飘带帆面、纸上舟体 | 人物抓住与帆面相连的绳索，牵引绘画船只 |
| 运动模糊、树影、流动云层 | 可卷起的风、柔软场景长带 | 人物握摇柄卷动，另一手引导长带进入卷轴 |
| 道路、轨道、台阶 | 逐渐显露的纸上路径 | 人物把末端铺平、推开折叠处或沿台阶攀行 |

## 动作检验

- 拉：线或边缘与手相连；手到物体之间存在张力；脚与身体倾斜可信。
- 编织或缝合：手接触材料；线明确穿过结构；人物坐在或站在可支撑的位置。
- 推或撑：工具末端接触受力物体或地面；人物姿态与推动方向一致。
- 铺或卷：人物握住布料或摇柄；材料连续进入摊开的平面或卷轴。
- 攀登：踩踏面明确；前后脚动作有区分；扶手或抓握位置确实存在。

## 避免机械套用

- 上方人物没有伸手动作时，不强改其姿态去配合幻想；让新增的小人物承担动作。
- 原片没有羽毛、颜料、船或围巾时，不引入这些物体来照搬参考故事。
- 不把植物统一画成银杏；保存原片可见叶形、树皮和枝条特征。
- 不把原片静止场景强行改成奔跑、风暴或戏剧灯光。
- 同类照片可分别使用桥、舟、吊床、路径或卷轴，但每张只用一个主要故事。
- 不依赖神秘光效、漂浮装饰或字幕来解释动作。让轮廓与接触点自己讲清楚。
