# Photo-to-Sketch Storytelling · 让照片长进画里

把真实照片中的一个元素延续到纸上，再让一个很小的人物参与它的变化。保持来源、变化和动作连贯；根据新照片重新设计情节。

## 1. 确认输入和本次产出

- 读取当前请求及可见上下文，区分需要编辑的原片、只提供风格的参考图、已有成图。
- 先实际查看每张输入图，再分析或编辑；不要假装看过无法读取的附件。读取失败时尝试宿主支持的附件下载方式；仍不可访问时，请用户重新附图。
- 用户只要分析或提示词时，只交付这些内容；用户要求处理照片时，直接执行图像编辑。不要用分析代替已授权的生成。
- 沿用明确的数量要求。用户在正在进行的照片处理任务中上传多张原片且未要求筛选时，分别处理，每张一幅；记录原片序号，不擅自丢弃近似照片。原片与参考图身份仍不明确时，只问这个关键问题。
- 用户未指定时，默认 2:3 竖幅、细腻铅笔或钢笔排线、少量淡彩、暖白纸、小人物一名、不添加文字或水印。用户的比例、人物数量和风格偏好优先。

## 2. 先找延伸元素，再设计动作

为每张原片建立简短的内部构图说明，不必把检查表全部展示给用户：

1. **保留什么**：人物脸部与姿态、物体外形、场景关系、光照、色调、植物叶形等。
2. **元素从哪里出来**：明确到原片中可见的位置，例如右侧藤编圆环的下端、白围巾现有末端、马尾根部。
3. **它如何变化**：保留材质和形状线索，变成柔软长带、织物小路、叶脉结构、小舟等一项主要形态。
4. **小人物做什么**：用拉、织、缝、铺、推、卷、攀登等具体动词，明确手的接触点、脚的落点、工具与物体的关系。
5. **颜色来自哪里**：提取原片两到四种主色与灰棕线色，下方淡化使用。

优先选择方向明确、轮廓可连续延长、材质可变成线条的真实元素。不要凭空添加一个物体作为延伸起点。用“元素 → 变化 → 动作”检验情节；例如“围巾 → 织物小路 → 小人物踩着折叠处向上走”。

按需读取 [story-patterns.md](references/story-patterns.md)，借鉴动作逻辑，不机械照搬题材。为近似照片选择不同故事或构图；不让每一张都成为相同的 S 形带子。

## 3. 设计连续的摄影与绘画过渡

- 保持上方真实摄影的质感，把幻想主要放在下方。通过向下扩展画布和适度重新取景安排空间，不压缩、拉长原片人物或物体。
- 横图通常能作为竖幅上方约 35%–45% 的区域；人物竖图可保留约 55%–65% 的摄影区域并向下扩展。把比例当作起点，优先保护脸部、完整姿态和主体连续性。
- 在连接处让摄影细节与手绘线条交叠：真实纹理逐渐简化为轮廓、疏密排线与薄色层；保持主体走向、透视和接触关系连续。
- 使用不规则的材质边缘与局部延伸，不用一条水平线把照片与插画分成两块。渐隐只辅助衔接，不能替代结构延续。
- 将主要绘画形态画大，小人物画小；通常小人物占画面高度约 5%–10%。保持足够暖白留白，外围减少线条和颜色。
- 使用细腻石墨、棕灰墨线、彩铅或透明水彩的组合；保留线条轻重和纸纹。避免粗重卡通线、塑料感 3D、满幅浓色和无关装饰。

## 4. 构造具体编辑提示词并执行

按需读取 [prompt-template.md](references/prompt-template.md)，把变量全部替换为本张照片的可见事实与单一情节，再提交。不要把多个候选情节混进一次生成。

明确标注每个输入的角色：原片为编辑目标，参考图只提供媒介、线条与过渡方式。禁止移植参考图的人物、植物品种、建筑、文字、界面或色板；原片内容优先。

- 优先使用宿主已有的图像生成/编辑工具；若宿主提供 imagegen 技能，遵循其工作流。
- 编辑本地图片前，通过宿主的图像查看工具加载它。提交路径引用时，只使用实际存在并已查看的目标与参考路径；使用近期图片引用时，确认目标都可包含。不要写死会话路径、文件 ID、用户账号或模型名称。
- 每张独立原片发起一次独立编辑。仅在宿主支持且不会混淆目标时并行执行，并保持原片序号与结果的对应关系。
- 没有图像编辑工具时，交付已填写的提示词并说明当前无法生成图片；不要把 SVG、HTML 或文字模拟当作生成结果，不静默转用需要用户密钥的外部 API。
- 尽量保护真实人物身份、面貌、衣着与姿态，但不要承诺生成式编辑能逐像素保留。用户明确要求原片像素完全不变时，先核实是否支持保留原片的合成流程；不能满足时说明这个实际限制。
- 默认创建新版本，不覆盖原片；按宿主的持久保存与展示规则交付。不要重复上传宿主已经自动保存的生成图。

## 5. 看成图，再做有针对性的修正

逐张查看结果，并按 [quality-checks.md](references/quality-checks.md) 检查。优先修复身份明显变化、主体连接断裂、植物叶形被参考图替换、人物无接触或多余肢体、界面文字混入等问题。

一次只修正一个主要问题，同时重复保留要求。修订时以当前成图为编辑目标，必要时补充原片作为身份或内容参考，并明确二者角色。不要无故重新设计已经成功的故事。

完成后简短说明结果。多图时按原片顺序给出“原片 → 情节”的对应关系，不依赖异步完成顺序。只说明实际检查过的表现，不把提示词里的要求当成成图已经达到的事实。
