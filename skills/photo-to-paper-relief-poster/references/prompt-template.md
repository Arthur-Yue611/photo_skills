# 提示词模板

## 无字底图（默认生产流程）

```text
根据输入原照片制作一张独立3:4竖版艺术海报的无字底图。
原片内容：[主体、姿势、结构、配色和必须保留的关系]。
提取这组主体，删减杂乱背景；保持结构、姿态、比例、核心配色、真实透视和支撑接触关系，不新增人物或物体。
采用非对称构图：主体整体位于中下部偏右，约60%画面为干净暖象牙白艺术纸留白。
左上与页脚是同一张连续纸面，留给后续排版；此阶段不要文字、字母、编号、标线、占位符或水印。
主体内部真实清晰，外围逐渐化为薄层手工纸浆浅浮雕、不规则纤维、矿物颜料、干刷露白与撕边，自然消融于纸面。
肌理只集中在主体附近，跟随[原片屋檐/枝干/衣褶/山势]走向，疏密错落，不围成均匀边框，不铺满背景。
柔和[原片侧光方向]，只有细微接触阴影；细腻、哑光、薄层、轻盈，不出现模型底座与塑料高光。
[有人物时：保留数量、头部方向、眼镜、发型、服饰和姿势，让面部周围几何吻合原片；可见脸随后回贴原片真实面部，不给脸加纸浆或新表情。]
输出一张完整3:4单幅。禁止上下双联、前后对比、多图网格、矩形照片贴框、教程页、额外人物、主体变形、文字、Logo、水印、均匀边框、泛黄污渍和满铺纹理。
```

## 完整通用提示词（宿主只能一次生成时）

```text
请将我上传的照片转化为一张独立的3:4竖版艺术海报，每张单独输出，不做原图与生成图对比，不分上下两栏，不拼图。
提取最有辨识度的主体[具体主体]，保留结构、姿态、比例、核心配色与空间关系，删减杂乱背景；不添加人物或原片没有的景物。
非对称构图，主体集中在中下部偏右，约60%画面为干净暖象牙白艺术纸留白。
主体内部保留清晰真实细节，外围逐渐转为薄层手工纸浆浅浮雕、不规则纤维、矿物颜料厚涂、干刷露白和撕边，自然消融于纸面。肌理集中在主体附近，疏密有变化，不围成均匀边框或铺满背景。
柔和侧光，以细微阴影表现薄层起伏，细腻、哑光、轻盈。
左上放小号细宋体或现代明朝体中文标题“[确切标题]”，按语义分一至两行；配更小的英文“[确切短句]”、编辑编号“[序号]”和一条从原片[具体色块]取色的短线。严格对齐，疏朗字距行距；页脚仅放微型文字“[说明]”，文字清楚克制。
[有人物时：不改变五官、脸型、肤色、表情、眼镜和身份特征；纸浆处理避开脸部。严格保护须由遮罩或随后原片回贴实现，不能仅凭提示词保证像素一致。]
高清输出自然材质。禁止对比版式、多图网格、矩形贴框、巨大粗重标题、密集文字、乱码、水印、额外人物、主体变形、塑料光泽、厚模型感、泛黄污渍和满铺纹理。
```

## 局部修订

- 留白不足：整体主体组等比例缩小约15–20%，向中下部偏右安放，扩展同一纸面；随后重新回贴原脸。
- 浮雕太厚：只减薄起伏与阴影，保留内部真实结构，去除模型底座与塑料高光。
- 纹理铺满：清除主体之外散乱纹理，让边缘自然淡出，恢复干净留白。
- 面部变化：回贴原片面部，不让模型重新画一个“更像的脸”替代严格保护。
- 文字错误：只修文字图层；一次生成时先去除错字再准确叠字，不重绘脸或场景。
