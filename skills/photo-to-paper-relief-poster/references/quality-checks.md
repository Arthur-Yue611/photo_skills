# 成品检查

| 检查项 | 通过标准 | 修正 |
| --- | --- | --- |
| 独立海报 | 每个输入对应一张3:4，无原图条、分栏与对比 | 重做单幅，不裁掉半张双联图冒充完整海报 |
| 主体关系 | 结构、数量、姿态、比例、透视、支撑、接触与反射正确 | 完整主体组一起移动缩放，修订问题区域 |
| 留白 | 约55–65%为安静纸面，主体偏右中下部 | 缩小主体、减少外围纹理，不洗掉内部结构 |
| 融合 | 内部真实清晰、边缘疏密变化，融入同一纸面 | 去除矩形贴图边和平均一圈白纤维 |
| 浅浮雕 | 薄层、微阴影、哑光，无泛黄污渍或满铺纹理 | 降低厚度与阴影，恢复干净紙面 |
| 原脸 | 核心取自原片，只均匀缩放平移，五官、眼镜和表情不改 | 回贴原脸，保留源照片自然模糊度 |
| 面部边缘 | 无重复鼻尖、嘴唇、眼镜、耳朵、双下颌或悬浮碎片 | 清理生成脸露出部分，再最后回贴原脸 |
| 中文 | 准确小号宋体/明朝体，最多两行，无缺字方框 | 用覆盖全部字形的字体重新叠字 |
| 英文和序号 | 拼写语法正确，序号对应本批次，无假日期地名 | 只改文字图层，不重绘画面 |
| 排版 | 左上对齐，短线取自原片；侧边或页脚仅微文案 | 缩字、删除重复说明，检查与主体间距 |
| 禁项 | 无手机UI、教程箭头、网格、贴框、额外人物、Logo、水印 | 使用真实原片，避免完整截图作为构图来源 |

## 保存后

1. 查看全幅的留白、姿态、位置和材质，不以脚本比例检查代替目视检查。
2. 放大脸、手、动物四肢及建筑轮廓；验证每个原脸核心像素，文字不得覆盖保护区域。
3. 逐字核对标题、英文、编号与微文案。编辑编号可以存在，但不得复制日期、账户和点赞数据。
4. 确认每张全尺寸输出独立存在、严格3:4，无占位符。原脸验证只针对明确蒙版内、等比例变换后的原片，不表示整幅生成场景都保持原图像素。
5. 可将单张文件打包供下载，不擅自制作对比图或网格预览。
