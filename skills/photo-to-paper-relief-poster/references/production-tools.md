# 排版与面部保护

## 默认顺序

生成无字3:4艺术底图 → 检查主体与留白 → 完成裁切/扩展 → 清理面部周围重影 → 均匀缩放回贴原脸 → 精确叠加文字 → 保存PNG并验证。

脚本不生成图片、不识别人脸、不自动选主体、不测量留白、不自动清除重复五官。它执行已核对的位置与蒙版、校验字体字形、取色和确定性排版。需要人工或智能体目视确定位置；不能把脸部检测框直接当成安全蒙版。

## 依赖与字体

```bash
python -m pip install "Pillow>=10" "fonttools>=4"
```

使用宿主真实安装的宋体/明朝体，如思源宋体、Noto Serif CJK或Windows宋体。脚本不附带字体，不下载字体，不假设某个系统路径存在；`--font` 必须指向实际字体文件。Windows常见宋体路径为 `C:/Windows/Fonts/simsun.ttc`，使用前确认存在；TTC可用 `--font-index` 选择集合内字体。英文可用同一字体，或用 `--latin-font` 提供另一真实字体。

fontTools会核对实际字形表，缺字时停止而非输出方框。字体有覆盖仍须查看最终字形、细字重与间距。不把字体水平挤压成高瘦字，也不擅自复制字体进入公开分发包。

## 排版命令

```bash
python scripts/compose_poster.py \
  --art art_base.png --source original.jpg --output poster.png \
  --title "旧门|春深" --subtitle "Spring at the old door" \
  --number 01 --footer "PAPER MEMORY" \
  --font /actual/path/to/CJK-serif-font.otf \
  --accent-point 420 680
```

`--title` 用 `|` 明确换行；4–8字中文也可自动分两行。默认1536×2048；用 `--width` 指定3的正整数倍，高度自动为4/3宽度。先检查无字底图严格3:4，脚本仅等比例调整尺寸，不拉伸、裁切或加矩形背景。

编号为编辑序号，不是日期。左上编号、中文标题、短线、英文严格对齐；页脚只有一行微文案。英文仅为准确短句，太长时修改内容而非压缩字形。短线用 `--accent-point X Y` 直接读取经过EXIF方向校正的原片像素；不传则从真实原片像素采样选择一个候选主色，仍需目视核对。

## 原脸蒙版协议

每个可见正脸或侧脸一个记录；多张原片分别准备各自JSON。所有原片坐标对应 **EXIF校正后的原片**，目标坐标对应 **最终1536×2048画布**（或指定的最终尺寸），不对应尚未缩放的生成底图。

```json
{
  "faces": [
    {
      "scale": 0.8,
      "source_anchor": [500, 600],
      "target_anchor": [900, 1100],
      "outer": [[450, 520], [570, 520], [585, 700], [450, 705]],
      "core": [[465, 540], [555, 540], [565, 685], [465, 690]],
      "feather": 5
    }
  ]
}
```

以上仅为协议示意，**不得拿示例点位直接处理真实人脸**。沿真实轮廓逐点选择：核心完整覆盖五官、下颌、眼镜和身份特征；外圈包含核心，并留给羽化适当的发际、颈部或周边缓冲。`feather` 单位为原片像素。原片肤色不得调色。

尺度以眼距和头部真实尺寸为依据，只允许正的统一缩放和平移，不做横纵独立拉伸、镜像、旋转、网格扭曲或生成式锐化。脚本计算 `tx = target_x - scale × source_x`、`ty`同理，采用统一仿射采样；完全不透明核心保留该变换后原片像素，羽化仅在核心之外。变换会发生插值，不应声称未缩放原片逐像素不变。

```bash
python scripts/compose_poster.py \
  --art art_base.png --source original.jpg --output poster.png \
  --title "林间|小驻" --subtitle "A quiet pause among trees" \
  --font /actual/path/to/CJK-serif-font.otf --faces faces.json
```

脚本拒绝核心越界、核心重叠、字体缺字、文字盖住保护核心、非3:4底图或覆盖原始输入。成功报告 `source_core_preserved` 和 `saved_png_verified`；它验证的是指定蒙版内的内容，不能发现漏标的鼻尖、错误对齐或轮廓外残留生成五官。

## 防止侧脸重影

原脸和生成脸轮廓可能不一致。最后回贴前先放大检查头部几何；生成鼻尖、嘴、镜框和耳部不得在原脸外围露出。必要时扩大外围缓冲，或用图像工具仅清理保护核心之外的旧轮廓和背景，再回贴原片核心。不要用透明混合把两张脸平均成第三张脸，也不要为凑合生成脸而压窄原脸。

脚本输出PNG使用原子写入，并检查保存像素。输入原片和无字底图均不被修改。结果已存在时选择新文件名，或在授权修订时用 `--overwrite`。
