# 适用照片与场景适配

| 照片类型 | 适用程度 | 处理要点 |
| --- | --- | --- |
| 古建筑、园林、门窗、屋檐、庭院 | 很适合 | 保留瓦片、门窗和树木关系；沿屋檐墙面让纸纤维消融，不自动加花枝或灯笼 |
| 花卉、枝叶、树木、植物静物 | 很适合 | 保留品种、花瓣和枝干走向；细枝内部保留空纸 |
| 山水、湖海、树林、乡村风景 | 很适合 | 提取一组山势、树影、倒影或房屋；不把风景贴成矩形 |
| 街景、现代建筑、桥梁、车站 | 适合 | 保留透视与轮廓，压低杂乱广告；不编造招牌文字 |
| 器物、书籍、陶瓷、食物静物 | 适合 | 保留外形、材质、支撑与接触；不成为厚塑料模型 |
| 动物、人与动物互动 | 适合 | 保留数量、物种、姿势、牵引和接触，不截断四肢 |
| 环境人像、旅行人像、少量人物合照 | 可以 | 保留完整主体组、动作和衣物；对可见正脸及侧脸回贴原片 |
| 夜景、灯光、反光、蓝调照片 | 可以 | 纸底仍暖象牙白，主体局部深色呼应原片；不继承其他Skill的深纸底 |
| 密集群像、面部大特写、证件照 | 非主要用途 | 难兼顾约60%留白和足够大的人脸；不要把脸缩到不可辨识来冒充保护 |
| 精确地图、工程图、严格商品色彩复现 | 不适用 | 艺术删减与肌理转换不提供技术精确性 |

## 主体与文案

- 一个主体或一个完整主体组可以包括门与花枝、人与坐骑、树与倒影；不要拆散相互关系。
- 横幅场景整体缩放、移动到竖幅，不分别乱移建筑、人物和反射。删减杂乱背景，但不删除主体组中的原有人物。
- 让轮廓支配纸浆方向：倒影上下对应、布褶沿原折线、树枝保留分叉、建筑保留垂直线和透视。
- 标题根据原片写。门与春花可用“旧门春深”，冷光湖面可用“湖上微光”，树林人物可用“林间小驻”；不要因此添加原片没有的春花、落雪或寺院。
- 编号是本次编辑序号。页脚或侧边用 `PAPER MEMORY`、`FIELD NOTE` 等中性微文案，不编造作者、展览、日期或地点。
- 非中式题材也适用：城堡、现代车站、骑马、湖边人像保持自身特征，不能强制变成中式园林。参考中的手机界面、账号、点赞数及最后两张教程讲解页的对比图和箭头均不属于海报风格。
