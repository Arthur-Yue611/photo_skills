# Check before delivery

- Confirm supported scenery or architecture, rather than a portrait or animal subject.
- Identify the complete subject; include all buildings in a complex, not only a tower.
- Keep original ratio, crop, viewpoint, horizon, subject structure and object locations.
- Use one complete boundary between opposing edges and two connected regions, without separate panels or photo islands.
- Check subject and frame proportions separately. Use actual silhouettes and the actual generated route, not just the proposal.
- Keep the macro boundary nearly straight with only slight smooth waves. Reject kinks, pronounced curves, ruler-straight lines and object-outline routes.
- Retain the approved square-cell scanner style, width and brightness. Change color locally with the scenery rather than using one unrelated neon hue.
- Make large square cells obvious at full-image size. Keep small objects recognizable without leaving photographic patches.
- Check building walls, domes, roof slopes, arches, window frames and rails specifically. Reject tiny painterly facets, smooth realistic walls and unchanged architecture.
- Keep source clear skies clear. Do not copy clouds or objects from style references.
- Check stripes, supports, ropes, building count, windows and incidental figures for changes or omissions.
- Restore original photography. Verify original pixels outside the deliberate pixel/scanner edit; a regenerated region is not an untouched original.
- Inspect the assembled seam at full frame and useful magnification. Do not accept clipped colored scan cells, an extra hard cut or a mismatched photo/art join just because a numerical report passed.
- Save each output separately, without text, borders, watermarks, decorative effects or grids.
- Keep approved references intact and limit revisions to the requested area.
- Distinguish effect previews from verified final composites. State any unresolved imbalance or restoration limit.

Test more than one scene type before judging generality. A successful house, village, castle or balloon example does not establish that every architecture or landscape photo will work identically.

- Check purposeful color clusters and depth: avoid noisy checkerboards, camouflage fragments and tiny polygon facets.
- Keep translucent scanner cells colored; reject a broad white core.
- If using the staged workflow, verify both the original photo and the pixel base outside the reviewed scan band.
- Do not claim a precise 20 percent grain increase without a measured baseline; it is an approximate reference target.
