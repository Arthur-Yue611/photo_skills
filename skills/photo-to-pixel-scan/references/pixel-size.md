# Pixel size and building treatment

Use the accepted reference's apparent grain size when available. The guides below describe a starting range, not exact measured cells or a fixed grid required of every model.

| Region | Guide at 1536-pixel image width | Treatment |
| --- | --- | --- |
| Broad sky, grass, hills and simple shapes | About 28–40 pixels per visible square | Large grouped flat-color cells; allow simpler fine detail. |
| Walls, roofs, towers and large architectural surfaces | About 20–30 pixels | Visible coarse square shading, stepped outlines and reduced material texture. |
| Windows, railings, furniture, ropes and small identity details | About 10–16 pixels, adjusted for object size | Clear pixel clusters that preserve recognition. |

Scale these guides with image width. A distant house cannot use the same absolute cells as a close wall if that erases its entire structure. Reduce cell size only enough to preserve its identity, while retaining obvious pixel character at normal viewing size.

Do not enlarge or reduce pixel grains on the whole image during a building-only revision. Keep approved background grains fixed and change only architecture.

## Buildings must visibly read as pixels

- Paint walls in a few source-matched flat tones with large square groups. Avoid both tiny brush facets and an entirely smooth wall with thin realistic windows.
- Draw sloped roofs, curves, arches, domes and rounded tower caps with stair-step silhouettes.
- Build window frames and railings from visible cells instead of fine continuous lines. Keep their positions, count and overall form.
- Replace brick, plaster and stone micro-texture with simple grouped shading. Preserve geometry rather than every surface mark.
- Include every architectural part inside the pixel region, not just surrounding foliage or ground.

A continuous flat plane does not need an artificial grid drawn on it. Use shape, stepped edges and discrete tonal clusters to make it read as pixel art. Do not apply an indiscriminate mosaic blur or turn it into a 3D block model.

If an approved version is supplied, preserve it as a rollback reference. A request for a slight reduction means a slight local change, not a return to fine-grained pixels.
