# Quality checks

## Source and layout

- Use the actual source photograph, not a social-media screenshot or generated upper-panel imitation.
- Verify 9:16 overall, 16:9 at the top, no added gaps, borders or text.
- Inspect the top crop for clipped faces, missing gestures and lost important relationships.
- Compare saved top RGB pixels with the oriented, cropped and uniformly resized source. This checks the displayed crop, not the entire original or file bytes.
- Keep output separate from both source and art inputs. Save lossless PNG.

## Lower art

- Retain at least one clearly recognizable source detail.
- Change scale, position or space meaningfully; do not merely blur or recolor the original layout.
- Use 3–5 differently sized broad overlapping color fields with fully blended edges.
- Let one field pass through a subject edge while keeping some details clear.
- Keep a dark colored base, soft light areas and a wide quiet region.
- Avoid an evenly lit pastel wallpaper when the request calls for a dark base.
- Avoid uniform blur, hard gradient boundaries, neon outlines, smoke, stars, coarse grains, paper relief, tears, frames, swatches, captions and logos.
- Preserve real subject count, species, main shape and contact relationships.

## Faces

- Preserve all identifiable faces, including side profiles, when present in the lower art.
- Compare features, expression, glasses, skin color and shape against the actual source.
- Use opaque source cores with uniform scale and translation; do not add alpha tint or glow over a protected core.
- Ensure the generated head/body matches the source face's orientation and placement.
- Inspect for doubled noses, mouths, eyes, jawlines or glasses around the pasted edge.
- Verify saved lower-core pixels against the transformed source. Pixels outside the core still need visual inspection.
- Never describe a prompt-only face as pixel-preserved.

## Revision and delivery

Fix only the affected lower area, then repeat assembly. Keep the top source and reviewed crop unchanged. Deliver one independent finished image per original. Identify actual untested steps or unresolved problems; script checks do not establish the quality of an image that has not been generated.
