# Photo-to-Watercolor Journal · 照片转水彩旅行手账

将原片场景整体转译成细钢笔与通透水彩的旅行手账页。保留原比例和光色，以不规则淡出边缘连接纸面，加入四个源色色卡及两行英文手写文字。

## 1. 查看输入，确认产出

- 实际查看每张原片及参考图，标明编辑目标与风格参考。读不到时尝试附件下载；仍无法读取时请用户重新附图，不假装分析。
- 识别截图中的成品区域；只研究线条、淡彩、纸感和布局，不复制状态栏、按钮、品牌水印或原图与成品上下对照排版。截图里与用户文字要求冲突的色块数量、图案色卡或文字重复，以用户要求为准。
- 要处理照片时执行图像编辑；只要提示词时只交付填写完整的提示词。多张独立原片默认每张一幅，保持序号与成图对应。
- 默认输出比例等于原始照片宽高比，不套成固定竖幅。在同一画幅内合理缩小景物，为底部留出约 15%–22% 空间；不拉伸主体、不切掉重要建筑或人物。用户明确比例优先。

## 2. 记录原片事实与四种源色

- 记录主体、地平线、建筑排列、道路或水面走向、人数、服饰、光源与时段。保留场景辨识度，不凭空改地点、建筑、天气或季节。
- 选择原片中四种有代表性的主色，优先按面积和场景重要性选择，兼顾明暗；避免四个近乎相同的色阶。夜景保留暗部、蓝色天空与实际存在的灯光色，不能为凑暖色添加原片没有的颜色。
- 需要可核对的色值且有本地执行能力时，运行 [extract_palette.py](scripts/extract_palette.py)。需要 Pillow；不可用时从原片目视取色，不为此强制安装依赖。
- 将四个具体颜色及可用 HEX 写入提示词。色卡取原片本身，不取风格截图、外圈背景或去饱和后的新颜色。插画淡彩可降低浓度；色卡仍保持源色。
- 脚本提供可追溯的候选主色，不保证最符合审美；可改选原片其他实际颜色。原片不足四种不同颜色时如实说明限制，不编造新色。

## 3. 设计插画与统一纸面

- 用黑色细钢笔轻勾轮廓，辅以低饱和、透明、柔和水彩薄层。保留建筑透视和人物姿态，不用粗重卡通描边、油画厚涂、3D 或摄影成品。
- 从景物边缘向外减少线条、淡化色层，形成湿画法晕染与不规则疏散边缘，让颜料进入同一纸面。无硬边框、水平切割、垂直分割、隔断、撕贴边或折痕。
- 按原片氛围确定外圈和底部纸面：夜景用适当深度的蓝灰或深调，暖日景用米色暖调，冷景用柔和蓝灰或冷调。夜景不一律纯黑，兼顾文字及色卡可见性。纸面连续过渡，不在底部另贴白纸。
- 保持细微水彩纸肌理、丰富主体与疏朗外围。留白指低细节纸面，不强制纯白。不添旅行贴纸、邮票、罗盘、微型人物等装饰。
- 人像按旅行场景插画处理，保留身份、人数、面貌、服装和姿态，不强改城市主题，也不承诺逐像素保留面容。

## 4. 安排两行文字与恰好四卡

- 右下角放恰好四个等大的圆角方形纯色色卡，默认 2×2 排列、间距一致；窄图可调整排列，始终四个且不遮挡主体或文字。
- 每卡内部仅一种指定源色；禁止渐变、景物缩略图、水彩图案、纹理、额外色块、色号标签和装饰阴影。纸面有肌理，色卡内部仍纯色。
- 底部放一行英文手写标题及其下一行英文短句，与右侧色卡错开。建议标题 2–5 词、短句 5–10 词，明确逐字文本，只出现一次。
- 根据可见景物、光照和情绪写文案，未经提供或确认不猜地点、日期、路线和建筑名。保留用户指定文字。
- 用自然轻重、略不规则基线的可读手写墨迹，不使用印刷标题或数字化标签感。夜景可用原片已有的浅色墨迹保持对比。
- 按需读取 [prompt-template.md](references/prompt-template.md)，组织单张提示词及日夜景例子。

## 5. 生成与定点修订

- 使用宿主图像编辑工具；有 imagegen 技能时遵循其流程。本地图像先查看再引用。不写死模型、账号、附件 ID 和会话路径。
- 每张独立原片单独编辑。工具允许时可并行，记录序号。无图像工具时说明能力并交付完整提示词，不将代码示意图当成生成成品。
- 查看实际输出，按 [quality-checks.md](references/quality-checks.md) 核对原比例、主体、纸面过渡、四卡数量与纯色、英文拼写及单次出现。
- 用当前成图修订最明显的问题，重申已成功部分的保留要求。生成工具不能保证精准颜色或文字时，如实说明，不声称色卡像素精准或文字绝对正确。
- 创建新版本，不覆盖原片；遵守宿主持久保存和展示规则，不重复上传已自动保存的生成图片。
