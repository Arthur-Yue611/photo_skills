# Photo to Color Fog

Add dense deep-teal fog and warm amber backlight to a photo. Keep people, poses, framing and scene layout recognizable. Preserve dry matte ground.

**Skill name:** `photo-to-color-fog`

**Suitable photos:** people with their surroundings, travel groups, walking back views, forests, fields, lakesides, buildings and streets. Scenes with foreground and background depth work best. Less suitable for ID photos, close-up faces or exact product-color work.

Upload an original and ask:

```text
Use $photo-to-color-fog to add deep teal and amber fog.
Keep the original faces, poses and composition.
Keep the ground dry and output each photo separately.
```

Read [the full prompt](references/prompt-template.md) and [AI instructions](SKILL.md). Your AI tool needs image viewing and editing. A skill provides instructions, not an image model. Identity and geometry still need visual checking; it does not guarantee unchanged facial pixels.

In this collection, keep the complete folder at `skills/photo-to-color-fog/`. Update the two README files at the repository root. Instructions and code use the collection MIT license; private photos are not included.
