# 照片转双色浓雾 · Photo to Color Fog

给照片加入深青绿冷雾和橙金暖逆光。保留人物身份、姿态、原构图与环境布局，让远景逐渐被雾遮住，地面保持干燥哑光。

**英文名称：** `photo-to-color-fog`

**适用照片：** 带环境的人像、旅行合照、行走背影、树林、草地、湖岸、建筑和街景。有明显前后景的照片更适合。证件照、面部大特写及要求精确还原商品颜色的照片不适合这套风格。

上传原始照片，然后输入：

```text
使用 $photo-to-color-fog 给照片加入深青绿与橙金双色浓雾。
保留原人物脸部、姿态、构图和环境，地面保持干燥。
保留原比例，每张单独输出。
```
